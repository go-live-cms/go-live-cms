# Sample images for the dev seed

`sample-image-1.jpg` … `sample-image-12.jpg` are the files behind the media
records the dev seeders create (`devModeUtil.CreateDummyData`). They are
embedded in the Go binary (`//go:embed` in `sample_media.go`) and copied into
`UPLOAD_PATH` at seed time, the same directory real uploads go to, so the media
library shows real images without network access.

## Source

Generated by [`generate.go`](generate.go) in this directory: abstract
gradients with soft circles, 800×600 JPEG at quality 80, about 15 KB each.
The output is deterministic. To regenerate (from the repo root):

```
go run ./devModeUtil/sampleimages/generate.go
```

If you replace them with photos, keep them small, keep the same file names
(existing dev databases point at them), keep them JPEG (the media rows say
`image/jpeg`), and update this file with each image's source and license.
